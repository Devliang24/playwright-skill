# playwright-skill

Playwright Skill is a Codex skill for creating, extending, and debugging local Playwright UI automation tests for web apps.

## What It Includes

- A concise `SKILL.md` workflow for Playwright UI test work.
- Reference guides for project intake, test architecture, selectors, user interaction, and local reporting.
- Helper scripts for inspecting frontend projects and scaffolding Playwright files.
- A TypeScript Playwright template with config, smoke test, fixture, and page object examples.

## Usage

Install this folder as a Codex skill, then ask Codex:

```text
Use $playwright-skill to add Playwright UI automation tests to this web project.
```

The skill focuses on local Playwright testing and reporting.
